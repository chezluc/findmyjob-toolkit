# Security

Do not commit:

- API keys
- SMTP passwords
- FTP credentials
- browser session data
- personal resumes
- private email archives
- local transcript dumps tied to a real person unless intentionally public

Before publishing or sharing:

- search for hardcoded absolute paths
- search for usernames, domains, and inboxes
- search for keychain lookup commands
- replace personal bridge IDs and extension IDs when needed
